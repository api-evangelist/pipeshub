PipesHub is an open-source, enterprise-ready workplace AI platform positioned as an open-source alternative to Glean. It unifies scattered business data by connecting to business and enterprise apps, provides explainable, permission-aware enterprise search across them, and powers AI agents that get work done. It can be self-hosted from its public GitHub repository (pipeshub-ai/pipeshub-ai) or used as a hosted app, and documents a developer API reference for building on its enterprise context layer.

**Areas:** Company · Artificial Intelligence · Enterprise Search · AI Agents · Open Source · Knowledge Management · Workplace AI

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for PipesHub: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
